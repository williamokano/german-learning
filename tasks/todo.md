# German Learning Course — Execution Plan

Goal: build a complete self-study German course (A1 → C1) in this repo.
Each topic = `lesson.md` (the class) + `exercises.md` (mixed, telc-style) + `solutions.md`.
Master curriculum lives in `CURRICULUM.md`. We produce topics **one at a time, in order** —
never more than 1–2 topics per session, so quality stays high.

## Conventions (decided 2026-06-11)

- [x] Instruction language: progressive immersion — English at A1–A2, mixed at B1, German-only at B2–C1
- [x] Answer keys: separate `solutions.md` per topic
- [x] Exercise volume: four-block architecture (Basistraining / Vertiefung /
      Prüfungstraining / Wiederholung+Selbsttest), ~28–32 exercises and 180–220 items
      per topic — see `tasks/lessons.md` (2026-06-11). Never ship below this.
- [x] Folder layout: `<LEVEL>/<NN-topic-slug>/{lesson.md,exercises.md,solutions.md}`

## Working agreement for future sessions

1. Read `CURRICULUM.md` + this file at session start.
2. Pick the next unchecked topic; read the *previous* topic's lesson first so vocabulary
   and grammar build on each other (recycling is mandatory).
3. Produce lesson → exercises → solutions, mark the checkbox, stop.
4. Any user correction about format/content → record it in `tasks/lessons.md` and apply
   retroactively only if the user asks.
