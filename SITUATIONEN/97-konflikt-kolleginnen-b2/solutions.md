# Block A — Basistraining

## Übung A1 — Ansprechen, zuhören oder lösen?

**Ansprechen:** **den Konflikt offen ansprechen**, **um ein Vier-Augen-Gespräch bitten**, **konkrete Beispiele nennen**, **die eigene Sichtweise erklären**
**Zuhören:** **der anderen Person zuhören**, **Verständnis zeigen**, **Rückfragen stellen**, **die Perspektive der Kollegin nachvollziehen**
**Lösen:** **gemeinsam eine Lösung suchen**, **einen Kompromiss finden**, **die Zusammenarbeit verbessern**, **das Ergebnis schriftlich festhalten**

## Übung B2 — Ansprechen und erklären

1. **b) Ich möchte einen Konflikt zwischen uns ansprechen.** — Eine klare Aussage ist der übliche Einstieg in ein solches Gespräch.
2. **c) Können wir gemeinsam eine Lösung finden?** — Eine direkte Frage öffnet den Weg zu einer gemeinsamen Lösung.
3. **a) Ich hatte das Gefühl, dass meine Arbeit kritisiert wurde.** — Eine Ich-Botschaft erklärt die eigene Sichtweise, ohne Vorwürfe zu machen.
4. **b) Sollen wir feste Regeln für Feedback vereinbaren?** — Eine direkte Frage klärt frühzeitig einen gemeinsamen Umgang für die Zukunft.
5. **c) Wie hast du deine Kritik eigentlich gemeint?** — Eine direkte Frage klärt Missverständnisse am schnellsten.
6. **a) Danke, dass du dir Zeit für dieses Gespräch nimmst.** — Ein höflicher Dank ist der übliche Einstieg in ein klärendes Gespräch.

## Übung B4 — Die Infos zum Konflikt lesen

1. **R** — So steht es ausdrücklich in den Infos zum Konflikt.
2. **F** — Ich-Botschaften wirken weniger vorwurfsvoll als direkte Anschuldigungen.
3. **R** — „Zuhören: die Sichtweise der anderen Person ernst nehmen, bevor man reagiert.“
4. **F** — Konkrete Beispiele helfen, Missverständnisse zu klären, nicht sie zu vergrößern.
5. **R** — „Vier-Augen-Gespräch: ist meist besser geeignet als eine Diskussion vor dem ganzen Team.“
6. **F** — Eine gemeinsame Vereinbarung hilft, den Konflikt langfristig zu lösen.

# Block C — Prüfungstraining

## Übung C1 — Wenn beim Konfliktgespräch etwas schiefgeht

1. **b) Ruhig bleiben und die eigene Sichtweise sachlich wiederholen.** — Ruhe und Sachlichkeit wirken deeskalierend auf eine defensive Reaktion.
2. **c) Eine kurze Pause vorschlagen und später ruhiger weiterreden.** — Eine Pause gibt beiden Seiten Zeit, sich zu beruhigen.
3. **a) Ruhig konkrete Beispiele und Fakten nennen.** — Konkrete Beispiele machen den Vorfall nachvollziehbar.
4. **b) Höflich darum bitten, das Gespräch unter vier Augen fortzusetzen.** — Eine höfliche Bitte schützt den vertraulichen Rahmen des Gesprächs.
5. **c) Vorschlagen, das Thema auch im Team zu besprechen.** — Ein Team-Thema profitiert von einer Besprechung im ganzen Team.
6. **a) Die Teamleitung als neutrale Vermittlung einbeziehen.** — Eine neutrale Vermittlung kann bei festgefahrenen Konflikten weiterhelfen.
