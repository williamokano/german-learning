# Anerkennung ausländischer Abschlüsse — B2

Ein ausländischer Abschluss muss oft erst anerkannt werden: den Antrag stellen, Zeugnisse mit beglaubigter Übersetzung einreichen und die Gleichwertigkeit prüfen lassen. Dieses Set übt genau das — einreichen, prüfen, nachqualifizieren, und was zu tun ist, wenn der Abschluss nur teilweise anerkannt wird. Grammatik nach Bedarf: Modalverben, Perfekt und Futur I. Blocks: A Wortschatz & Redemittel → B Dialoge → C Wenn es schiefgeht → D Wiederholung. Answers in solutions.md.

## Übung B4 — Die Infos zur Anerkennung lesen

> **Info — Anerkennung ausländischer Abschlüsse**
>
> - **Antrag:** kann man bei der zuständigen
>   **Anerkennungsstelle** stellen.
> - **Zeugnisse:** müssen oft **beglaubigt übersetzt** werden.
> - **Gleichwertigkeit:** wird mit dem **deutschen
>   Referenzberuf** verglichen.
> - **Nachqualifizierung:** ist bei **teilweiser
>   Gleichwertigkeit** oft nötig.
> - **Bearbeitungszeit:** kann **mehrere Monate** dauern.
> - **Reglementierte Berufe:** (z. B. Ärztin, Lehrer) brauchen
>   oft **zwingend** eine Anerkennung.

Richtig (R) oder falsch (F)?


1. Die Anerkennung kann man bei der zuständigen Anerkennungsstelle beantragen. — Recognition can be applied for at the responsible recognition authority. ( )
2. Ausländische Zeugnisse müssen nie übersetzt werden. — Foreign certificates never need to be translated. ( )
3. Die Gleichwertigkeit wird mit einem deutschen Referenzberuf verglichen. — Equivalence is compared with a German reference profession. ( )
4. Bei teilweiser Gleichwertigkeit ist eine Nachqualifizierung nie nötig. — When equivalence is only partial, a bridging course is never needed. ( )
5. Die Bearbeitungszeit kann mehrere Monate dauern. — Processing time can take several months. ( )
6. Für reglementierte Berufe wie Ärztin oder Lehrer braucht man keine Anerkennung. — For regulated professions like doctor or teacher, no recognition is needed. ( )

# Block C — Prüfungstraining

## Übung C1 — Wenn bei der Anerkennung etwas schiefgeht

Wähle die beste Reaktion.

1. Ihr Abschluss wird nur teilweise anerkannt. — Your degree is only partially recognized.  a) Den Beruf komplett aufgeben.  b) Sich über die möglichen Wege zur Nachqualifizierung informieren.  c) Den Bescheid einfach ignorieren.
2. Die Anerkennungsstelle fordert fehlende Unterlagen nach. — The recognition authority requests missing documents.  a) Den Antrag einfach zurückziehen.  b) Die Unterlagen nie einreichen.  c) Die fehlenden Unterlagen schnellstmöglich nachreichen.
3. Die Bearbeitung Ihres Antrags dauert deutlich länger als angekündigt. — Processing your application takes much longer than announced.  a) Höflich nach dem aktuellen Bearbeitungsstand fragen.  b) Einfach nichts mehr unternehmen.  c) Einen komplett neuen Antrag woanders stellen.
4. Der passende Anpassungslehrgang ist gerade nicht verfügbar. — The right adaptation course isn't currently available.  a) Ganz auf die Anerkennung verzichten.  b) Nach alternativen Anbietern oder einem späteren Kurstermin fragen.  c) Sich einen falschen Nachweis besorgen.
5. Sie merken, dass die beglaubigte Übersetzung fehlerhaft ist. — You notice the certified translation contains errors.  a) Die fehlerhafte Übersetzung einfach so einreichen.  b) Selbst versuchen, den Fehler zu korrigieren.  c) Eine korrigierte Übersetzung beim Übersetzungsbüro anfordern.
6. Sie sind mit dem Bescheid der Anerkennungsstelle nicht einverstanden. — You disagree with the recognition authority's decision.  a) Fristgerecht schriftlich Widerspruch einlegen.  b) Den Bescheid einfach akzeptieren, ohne nachzufragen.  c) Der Behörde eine wütende Nachricht schreiben.

## Übung D2 — Beantragen, ein Problem, die Lösung

> Du beantragst die Anerkennung deines ausländischen
Studienabschlusses. Nach einigen Monaten kommt der Bescheid:
Dein Abschluss ist nur teilweise gleichwertig.

Bei der Beantragung müssen vorkommen:
1. den Antrag auf Anerkennung stellen
2. die Zeugnisse mit beglaubigter Übersetzung einreichen
3. auf den Bescheid warten

Beim Problem müssen vorkommen:
4. erfahren, dass der Abschluss nur teilweise anerkannt wird
5. sich enttäuscht fühlen
6. sich über die nächsten Schritte informieren

In der Lösung müssen vorkommen:
7. eine Nachqualifizierung beginnen
8. einen Anpassungslehrgang absolvieren
9. die volle Anerkennung erhalten
10. sich über den Erfolg freuen


**Your task:** Schreib drei Teile: den Antrag auf Anerkennung deines ausländischen Abschlusses stellen, ein Problem, weil der Abschluss nur teilweise anerkannt wird, und die Lösung. Zusammen 16–20 Sätze.

Use:
- [ ] höfliche Frage: „Können Sie mir bitte erklären, welche Unterlagen ich brauche?“
- [ ] Perfekt: „Ich habe den Antrag gestellt.“
- [ ] Futur I: „Ich werde die Nachqualifizierung machen.“

Self-check:
- [ ] Wird die Beantragung klar beschrieben?
- [ ] Klingt die Reaktion auf die Teilanerkennung realistisch?
- [ ] Wird die Nachqualifizierung als Lösung erwähnt?
- [ ] Kommen alle 10 Punkte vor?
