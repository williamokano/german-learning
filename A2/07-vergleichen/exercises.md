## Übung A9 — So … wie: Sätze bauen

> 1. Berlin 3,7 Mio. / München 1,5 Mio. (groß, unequal) → München ist nicht so groß wie Berlin.

**Your task:** Rewrite each comparison using `so … wie` (equal) or `nicht so … wie` (unequal, as indicated).
