## A3 — `als` oder `wie`?

1. **als** — Berlin ist größer *als* Wien. (unequal: bigger than)
2. **wie** — München ist so schön *wie* Berlin. (equal: as … as)
3. **wie** — nicht so teuer *wie* (equal negated)
4. **als** — schneller *als* ich. (unequal)
5. **wie** — genauso gut *wie* (equal)
6. **als** — höher *als* in Hamburg. (unequal)
7. **wie** — so gut *wie* ihre Mutter. (equal)
8. **als** — besser *als* das alte. (unequal)
9. **wie** — so warm *wie* in Spanien. (equal)
10. **als** — weniger Einwohner *als* Deutschland. (unequal)

**Key rule:** `als` = unequal comparison · `wie` = equal comparison (so/genauso … wie)

## B2 — Finde den Fehler

1. Berlin ist größer **als** Wien. *(wie → als: unequal comparison)*
2. Das ist der schnellst**e** Zug in Deutschland. *(missing attributive ending -e)*
3. München ist so groß **wie** Berlin. *(als → wie: equal "so … wie")*
4. Das blaue Kleid ist elegant**er** als das rote. *(elegantere → eleganter: predicative comparative takes no extra ending)*
5. Er ist älter **als** ich. *(wie → als: unequal)*
6. Das ist das best**e** Ergebnis in der Klasse. *("am besten" is predicative; before a noun → attributive: "das beste")*
7. Sie singt **lieber** als ihr Bruder. *("gern" → "lieber" because of "als" — comparative needed)*
8. Hoch → Superlativ attributiv: der **höchste** Berg. *(hochste → höchste: irregular)*
9. Dieses Modell kostet mehr **als** das andere. *(wie → als: unequal)*
10. Der **kälteste** Monat ist der Januar. *("Am kälteste" → attributive: der kälteste)*

## Häufige Fehler — Zusammenfassung (Common error summary)

| Fehler | Richtig | Regel |
|---|---|---|
| *Berlin ist größer **wie** Wien.* | Berlin ist größer **als** Wien. | Unequal → `als` |
| *München ist so groß **als** Berlin.* | München ist so groß **wie** Berlin. | Equal → `wie` |
| *Das ist der schnellst Zug.* | Das ist der schnellst**e** Zug. | Attributive needs ending (-e, Nom. m) |
| *Das ist am besten Ergebnis.* | Das ist das best**e** Ergebnis. | Attributive: article + superlative + ending |
| *der hochste Berg* | der höchst**e** Berg | `hoch` is irregular: höchst- |
| *teurerer* | **teurer** | `-er` replaces inner `-e-`; don't double |
| *gut → guter* | gut → **besser** | Fully irregular — must memorize |
| *viel → vieler* | viel → **mehr** | Fully irregular |
| *gern → gerner* | gern → **lieber** | Fully irregular |
