## A2 — Präposition einsetzen (1)

1. **auf** (warten auf + Akk)
2. **an** (denken an + Akk)
3. **für** (sich interessieren für + Akk)
4. **über** (sprechen über + Akk)
5. **auf** (antworten auf + Akk)
6. **auf** (sich freuen auf — future event: Besuch hasn't happened yet)
7. **über** (sich ärgern über + Akk)
8. **über** (sich freuen über — she already received it)
9. **nach** (fragen nach + Dat)
10. **an** (schreiben an + Akk — when writing *to* a person)

## A3 — Akkusativ oder Dativ nach der Präposition?

1. **a** — `den` Bus (m Akkusativ after `warten auf`)
2. **a** — `die` Familie (f Akkusativ after `denken an`)
3. **b** — `dem` Weg (m Dativ after `fragen nach`) ⚠️ only Dativ verb in this set
4. **a** — `das` Problem (n Akkusativ after `sprechen über`)
5. **b** — `einen` Freund (m Akkusativ, indefinite article after `schreiben an`)
6. **a** — `der` Adresse (f Dativ after `fragen nach`)
7. **b** — `das` Wochenende (n Akkusativ after `sich freuen auf`)
8. **b** — `die` Verbindung (f Akkusativ after `sich ärgern über`)

## A4 — `sich freuen über` oder `sich freuen auf`?

1. **auf** — das Konzert nächste Woche (future event → `auf`)
2. **über** — die gute Note (past/current fact: she has the grade already → `über`)
3. **auf** — den Videoanruf am Freitag (future event → `auf`)
4. **auf** — den Sommer (future → `auf`)
5. **über** — deine Nachricht, die er gerade gelesen hat (he already read it → `über`)
6. **über** — das neue Buch, das sie schon hat (she already has it → `über`)
7. **auf** — unsere nächste Reise (future → `auf`)
8. **über** — das Geschenk, das sie schon ausgepackt haben (already opened → `über`)

## A5 — Vollständige Sätze

1. Ich **denke an** dich, wenn du nicht schreibst.
2. Er **ärgert sich über** seinen Chef, weil der Termin wieder verschoben wurde.
3. Wir **schreiben an** unseren Lehrer einen Brief.
4. Anna **wartet auf** den Bus — er kommt nicht!
5. Bruno **interessiert sich für** deutsche Musik.

## A6 — Sätze umformen

**A — Person → personal pronoun:**

1. Ich denke an **ihn**. (meinen Vater = er → Akk = ihn)
2. Er wartet auf **sie**. (Frau Weber = sie → Akk = sie)
3. Wir schreiben an **sie**. (unsere Freundin = sie → Akk = sie)

⚠️ The preposition stays: `denken an`, `warten auf`, `schreiben an` — do not change the preposition.

**B — Thing → Pronominaladverb:**

4. Ich interessiere mich **dafür**. (für + das Thema → dafür)
5. Wir sprechen **darüber**. (über + das Problem → darüber)
6. Er antwortet **darauf**. (auf + die E-Mail → darauf)

## A7 — Konjugation: Verben mit Präpositionen

1. Ich **warte** auf eine Nachricht.
2. Du **wartest** auf den Bus.
3. Er **wartet** auf eine Antwort.
4. Wir **ärgern uns** über das schlechte WLAN.
5. Ihr **ärgert euch** über die Werbung. (reflexive pronoun changes: ihr → euch)
6. Sie **freuen sich** auf den Urlaub. (reflexive pronoun: sie pl. → sich)
7. Ich **interessiere mich** für Podcasts.
8. Frau Weber **interessiert sich** für das Projekt.

## A8 — `fragen nach` (Dativ)

All answers use Dativ. Remember: m `der` → `dem`, f `die` → `der`, n `das` → `dem`, indef m `ein` → `einem`.

1. Ich frage nach **der** Uhrzeit. (die Uhrzeit, f → Dat: der)
2. Ich frage nach **dem** Passwort. (das Passwort, n → Dat: dem)
3. Ich frage nach **dem** Preis. (der Preis, m → Dat: dem)
4. Ich frage nach **der** Haltestelle. (die Haltestelle, f → Dat: der)
5. Ich frage nach **dem** WLAN-Passwort. (das Passwort, n → Dat: dem)
6. Ich frage nach **einem** freien Platz. (ein Platz, m indef → Dat: einem)

## A9 — Verneinung: `nicht` einsetzen

1. Ich warte **nicht** auf eine Antwort.
2. Er antwortet **nicht** auf meine E-Mail.
3. Wir interessieren uns **nicht** für Werbung.
4. Anna ärgert sich **nicht** über die Verbindung.
5. Bruno denkt **nicht** an die Hausaufgaben.
6. Ich freue mich **nicht** auf das Meeting.

## A10 — Wortschatz: Paare finden

1. d — die Verbindung = connection
2. a — die Folge = episode
3. c — die Sendung = programme, broadcast
4. b — die Empfehlung = recommendation
5. g — das WLAN = Wi-Fi
6. f — der Anruf = phone call
7. h — die Werbung = advertisement, commercial
8. e — das Abonnement = subscription

## A11 — Verben: Perfekt bilden

1. anrufen → Ich habe **angerufen**. (separable: an + ge + rufen)
2. herunterladen → Ich habe **heruntergeladen**. (separable: herunter + ge + laden)
3. abonnieren → Ich habe **abonniert**. (-ieren verb → no ge-, ends in -iert)
4. kommentieren → Ich habe **kommentiert**. (-ieren verb → no ge-)
5. schicken → Ich habe **geschickt**. (regular weak verb)
6. hochladen → Ich habe **hochgeladen**. (separable: hoch + ge + laden)
7. teilen → Ich habe **geteilt**. (regular weak verb)

# Block B — Vertiefung

## B1 — Dialog ergänzen

1. **warte auf** (warten auf: waiting for Bruno's message)
2. **interessierst du dich für** (sich interessieren für)
3. **Sprechen wir über** (sprechen über — verb-second after no position-1 element; also fine: "Dann sprechen wir über")
4. **freue mich auf** (sich freuen auf — the Filmabend hasn't happened yet → auf)
5. **ärgerst du dich über** (sich ärgern über)
6. **antworte … auf** (antworten auf)

## B2 — Finde den Fehler

1. ✗ `warte für` → ✓ **warte auf** (warten takes `auf`, not `für`)
2. ✗ `interessiert sich auf` → ✓ **interessiert sich für** (sich interessieren takes `für`)
3. ✗ `freuen uns über` → ✓ **freuen uns auf** (future event not yet experienced → `auf`)
4. ✗ `ärger` → ✓ **ärgert** (3rd person sg. verb ending -t)
5. ✗ `Er antwortet auf meine E-Mail nicht` — word order is actually fine in German. Better target: → ✓ **Er antwortet nicht auf meine E-Mail.** (`nicht` before the prepositional phrase is most natural)
6. ✗ `schreibe an meinen Freund einen Brief` → ✓ **schreibe meinem Freund einen Brief** OR **schreibe einen Brief an meinen Freund** (`an + Akk` = direction to person; indirect obj. in Dativ without preposition also possible)
7. ✗ `fragt nach die Adresse` → ✓ **fragt nach der Adresse** (`nach` takes Dativ: die → der)
8. ✗ `denke oft an meinen Bruder ihm` → ✓ **denke oft an meinen Bruder** (drop `ihm` — do not add a redundant pronoun)
9. ✗ `sprechen für das Problem` → ✓ **sprechen über das Problem** (`sprechen` takes `über`)
10. ✗ `freut sich über seinen nächsten Urlaub` → ✓ **freut sich auf seinen nächsten Urlaub** (hasn't happened yet → `auf`)

## B3 — Frage und Antwort verbinden

1. **c** — Worauf wartest du? → Auf eine E-Mail von meiner Uni.
2. **g** — Worüber ärgerst du dich? → Über das langsame Internet.
3. **d** — Woran denkst du gerade? → An meinen Urlaub nächsten Sommer.
4. **a** — Worüber sprechen Sie? → Über Serien und Filme.
5. **b** — Wofür interessierst du dich? → Für klassische Musik.
6. **e** — Auf wen wartest du? → Auf meine Schwester — sie ist spät. (person → `auf wen`, not `worauf`)
7. **f** — Wonach fragst du? → Nach dem WLAN-Passwort.
8. **h** — Worauf antwortest du? → Auf eine Nachricht von gestern.

## B4 — Satzbau

1. Ich warte auf deine Antwort.
2. Bruno ärgert sich über die langsame Verbindung.
3. Interessierst du dich für Podcasts?
4. Wir sprechen oft über Medien.
5. Anna denkt an ihre Eltern.
6. Ich antworte gerne auf Ihre E-Mail.
7. Herr Steinmeyer fragt nach dem Rezept. *(also fine: "Die Apothekerin fragt Herrn Steinmeyer nach dem Rezept")*
8. Sie freut sich über die neue Nachricht.

## B5 — Fragen schreiben

1. **Worauf** wartest du? (thing: der nächste Zug → Pronominaladverb form)
2. **Worüber** sprecht ihr? (thing: das neue Filmprogramm)
3. **Wofür** interessierst du dich? (thing: Dokumentationen)
4. **Auf wen** wartest du? (person: seine Freundin → use `auf wen`, not `worauf`)
5. **Woran** denkst du? (thing/event: das Gespräch)
6. **Worüber** ärgerst du dich? (thing: die Werbung)
7. **Worauf** freut sich Bruno? (thing: der Videoanruf)

## B6 — Übersetzen (EN → DE)

1. Ich warte auf deine Nachricht.
2. Sie interessiert sich für deutsche Podcasts.
3. Wir sprechen über die neue Serie.
4. Er ärgert sich über das schlechte WLAN.
5. Ich freue mich auf unseren Anruf morgen. (future → `auf`)
6. Sie freut sich über die nette Nachricht, die sie gerade bekommen hat. (past receipt → `über`)
7. Sie fragen nach dem Preis des Abonnements.
8. Ich antworte heute Abend auf deine E-Mail.

## B7 — Mediengewohnheiten

Model answers (also fine: any grammatically correct sentence using the cued verb):

1. Ich interessiere mich für Serien / Podcasts / Filme.
2. Ich freue mich immer auf neue Folgen meiner Lieblingsserie.
3. Ich ärgere mich über das langsame WLAN / über zu viel Werbung.
4. Ja, ich denke oft an meine Familie / meine Eltern.
5. Ja, ich schreibe meiner Familie täglich / jede Woche. *(also fine: `Ja, ich schreibe an meine Familie.`)*

## B8 — `nicht` oder `kein-`?

1. Ich warte auf **keine** Antwort. (`kein-` negates a noun with indefinite article: eine Antwort → keine Antwort)
2. Er antwortet auf meine Nachrichten **nicht**. (`nicht` negates the verb action)
3. Wir haben **kein** WLAN in dieser Wohnung. (kein + Nomen ohne bestimmten Artikel)
4. Anna freut sich **nicht** auf den Montagmorgen. (`nicht` negates the verb phrase)
5. Das ist **keine** Empfehlung — das ist Werbung! (kein- + noun)
6. Ich schreibe **nicht** so oft an meine Familie, wie ich möchte. (`nicht` negates the adverb `so oft`)

## C3 — Sprachbausteine Teil 2

> Hallo! Ich heiße Minh und wohne seit einem Jahr in Berlin. Ich (1)**INTERESSIERE** mich sehr (2)**FÜR** soziale Medien. Jeden Abend (3)**SCHREIBE** ich (4)**AN** meine Eltern in Vietnam — ich vermisse sie sehr. Ich (5)**FREUE** mich immer über ihre Nachrichten, weil sie zeigen, dass alles gut ist. Manchmal (6)**WARTE** ich (7)**AUF** eine Antwort, wenn mein Bruder nicht schreibt. Ich (8)**ANTWORTE** immer schnell auf alle Nachrichten von zu Hause. Manchmal (9)**ÄRGERE** ich mich (10)**ÜBER** das schlechte WLAN hier — aber das ist das einzige Problem!

*Not needed (10 distractors):* **NACH · DENKE · MIT · VON · BEI · FRAGE · HÖRE · IN · SPRECHE · ZU**

Explanations:
- (1)+(2): `sich interessieren für` — verb then preposition, both gaps.
- (3)+(4): `schreiben an + Akk` — writing *to* someone.
- (5): `sich freuen über` — already written in text after the gap.
- (6)+(7): `warten auf` — verb then preposition, both gaps.
- (8): `antworten auf` — preposition `auf` already written in text after the gap.
- (9)+(10): `sich ärgern über` — verb then preposition.

## D2 — Odd-one-out

1. **hören für** — wrong; `hören` doesn't take `für`; others are correct verb+preposition chunks
2. **die Verbindung** — this is a technical term (connection), while the others (Folge, Sendung, Serie) all refer to TV/streaming content
3. **suchen nach** — incorrect chunk; `suchen` takes the Akkusativ directly without `nach`; others are correct media verbs (also fine to argue `kommentieren` is stylistically different, but `suchen nach` is grammatically wrong)
4. **sich legen auf** — `sich legen` uses `auf + Akk` for location but is NOT a fixed-preposition expression of feeling/opinion; the others are all emotion/interest expressions
5. **das Rezept** — a medical/cooking term; the others (Smartphone, WLAN, Handy) are digital/communication devices
6. **buchstabieren** *(L1)* — a spelling/alphabet verb from Lektion 1; the others (streamen, teilen, liken) are all social-media/internet verbs

## D3 — Rückblick

**A2/L5 — Reflexive Verben:**

1. Ich fühle **mich** nicht gut. (Akk reflexive, 1st sg. = mich)
2. Er putzt **sich** die Zähne. (Dat reflexive, 3rd sg. = sich; same form as Akk for 3rd person)
3. Wir ruhen **uns** aus. (Akk reflexive, 1st pl. = uns; separable: ruhen … aus)

**A1/L11 — Perfekt:**

4. angerufen (separable: an + ge + rufen)
5. geschrieben (strong verb)
6. bekommen (inseparable be- → no ge-)
