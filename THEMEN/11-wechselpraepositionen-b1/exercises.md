# Wechselpräpositionen: Ort, Zeit und da-/wo-Komposita — B1

Standalone drill set, not tied to any lesson. Builds on the A2 set's Wo?/Wohin? spatial system with three B1 extensions: (1) the standard written contractions (in dem → im, in das → ins, an dem → am, an das → ans, auf das → aufs); (2) time expressions with the same nine prepositions, which are almost always Dativ regardless of movement, since time doesn't have a "direction" the way space does (am Montag, im Frühling, vor zwei Jahren); and (3) da(r)-/wo(r)-compounds used for location when the reference is a THING, not a person (Der Schlüssel liegt auf dem Tisch. Wo liegt er? — Er liegt darauf.). Blocks: A Basistraining → B Vertiefung → C Sprachbausteine → D Wiederholung. Answers in solutions.md.
