# Block A — Basistraining

## Übung A1 — Welcher Fall? Eine Verbliste

|  | Fall | Beispiel |
|---|---|---|
| helfen | **Dativ** | **Ich helfe dem Mann.** |
| danken | **Dativ** | **Ich danke der Frau.** |
| gefallen | **Dativ** | **Das gefällt mir.** |
| gehören | **Dativ** | **Das gehört ihm.** |
| sehen | **Akkusativ** | **Ich sehe den Mann.** |
| kennen | **Akkusativ** | **Ich kenne die Frau.** |
