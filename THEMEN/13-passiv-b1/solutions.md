# Block C — Prüfungstraining

## Übung C1 — Sprachbausteine Teil 1 — Die Autofabrik

1. **a) werden** — Vorgang, Präsens → werden.
2. **b) wurden** — Vorgang, Präteritum → wurden.
3. **c) ist** — Vorgang, Perfekt → ist … worden.
4. **a) wird** — Vorgang, Präsens → wird.
5. **b) muss** — Notwendigkeit im Passiv mit Modalverb → müssen.
6. **c) können** — Möglichkeit im Passiv mit Modalverb → können.
7. **b) soll** — Plan/Absicht im Passiv mit Modalverb → sollen.
8. **a) werden** — Vorgang, Präsens → werden.
