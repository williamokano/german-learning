# Passiv: Vorgang, Zustand und Modalverben — B1

Standalone drill set, not tied to any lesson. The Passiv shifts focus from who does something to what happens to it: Der Lehrer korrigiert die Tests (Aktiv) → Die Tests werden korrigiert (Passiv) — the doer can still be named with von + Dativ, but is often left out entirely. Vorgangspassiv (werden + Partizip II) describes the process itself across every tense (wird/wurde/ist … worden gebaut). A separate form, Zustandspassiv (sein + Partizip II), describes only the resulting state (Die Tür ist geöffnet — it's already open, no more opening happening). Modal verbs combine with the Passiv too: Die Aufgabe muss erledigt werden. Blocks: A Basistraining → B Vertiefung → C Sprachbausteine → D Wiederholung. Answers in solutions.md.
