## Übung A2 — Präposition + Pronomen

1. **a) sie** — ohne + Akkusativ; die Antwort ist feminin → sie.
2. **c) ihm** — vor + Dativ (immer) → ihm.
3. **a) es** — für + Akkusativ (immer); das Projekt ist neutrum → es.
4. **b) ihnen** — mit + Dativ (immer); Kollegen = Plural → ihnen.
5. **a) ihn** — ohne + Akkusativ (immer) → ihn.
6. **b) ihr** — zu + Dativ (immer) → ihr.

# Block B — Vertiefung

## Übung B1 — Zwei Objekte: die richtige Reihenfolge

1. Ich schenke meinem Vater ein Buch
   _Zwei Nomen: Dativ (meinem Vater) vor Akkusativ (ein Buch)._
2. Ich schenke es ihm
   _Zwei Pronomen: Akkusativ (es) vor Dativ (ihm)._
3. Ich schenke es meinem Vater
   _Pronomen + Nomen: das Pronomen (es) kommt immer zuerst, egal welcher Fall._
4. Ich schenke ihm ein Buch
   _Pronomen + Nomen: das Pronomen (ihm) kommt immer zuerst, egal welcher Fall._
5. Der Lehrer erklärt den Schülern die Aufgabe
   _Zwei Nomen: Dativ (den Schülern) vor Akkusativ (die Aufgabe)._
6. Ich möchte es ihr geben
   _Modalverb + zwei Pronomen (Akk vor Dat) + Infinitiv am Satzende._

# Block D — Wiederholung & Selbsttest

## Übung D1 — Wiederholung: Wortstellung

1. Der Verkäufer zeigt dem Kunden das neue Modell
   _Zwei Nomen: Dativ vor Akkusativ._
2. Der Verkäufer zeigt es ihm
   _Zwei Pronomen: Akkusativ vor Dativ._
3. Der Verkäufer zeigt es dem Kunden
   _Pronomen (es) vor Nomen (dem Kunden)._
4. Ich kann ihr das Geschenk nicht geben
   _Pronomen (ihr) vor Nomen (das Geschenk); nicht vor dem Infinitiv._
5. Weil er es ihr schon erklärt hat
   _Nebensatz: Verb ans Ende; im Mittelfeld Akkusativ (es) vor Dativ (ihr)._

## Übung D2 — Selbsttest

1. **a) es** — über + Akkusativ; das Angebot ist neutrum → es.
2. **b) ihm** — helfen + Dativ → ihm.
3. **a) sie** — bezahlen + Akkusativ; die Rechnung ist feminin → sie.
4. **a) sie** — einladen + Akkusativ; Plural → sie.
5. **b) ihm** — schreiben + Dativ (jemandem etwas schreiben) → ihm.
6. **a) sie** — akzeptieren + Akkusativ; die Idee ist feminin → sie.
