# irgendwo, irgendwann, irgendwie, irgendein … — A2

Mit irgend- sagt man, dass etwas unbestimmt ist — man weiß nicht genau wo, wann, wie, wer oder welche. irgendwo = an einem Ort, den ich nicht kenne (Ich habe den Schlüssel irgendwo verloren.). irgendwann = zu einem unbestimmten Zeitpunkt. irgendwie = auf eine Art, die ich nicht erklären kann. irgendwas / irgendetwas = eine Sache. irgendwer / irgendjemand = eine Person. irgendein- steht vor einem Nomen und wird wie ein dekliniert (irgendein Buch, irgendeine Frage, irgendeinen Grund). Blocks: A Basistraining → B Vertiefung → C Sprachbausteine → D Wiederholung. Answers in solutions.md.
