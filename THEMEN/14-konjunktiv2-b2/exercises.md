# Konjunktiv II der Vergangenheit — B2

Standalone drill set, not tied to any lesson. To talk about the past unreal — regrets, missed chances, things that didn't happen — Konjunktiv II uses hätte/wäre + Partizip II: Wenn ich das gewusst hätte, hätte ich anders gehandelt (but I didn't know, so I didn't). Modal verbs join in with a double-infinitive construction: Ich hätte das machen sollen (I should have done that, but didn't) / Ich hätte kommen können (I could have come, but didn't). Blocks: A Basistraining → B Vertiefung → C Sprachbausteine → D Wiederholung. Answers in solutions.md.
