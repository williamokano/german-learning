# werden — Vollverb, Futur, Passiv — B1

Ein Verb, drei Aufgaben. 1) Vollverb werden = sich verändern / etwas werden: Es wird kalt. Sie wird Ärztin. Perfekt mit sein und geworden: Es ist kalt geworden. 2) Futur I: werden + Infinitiv: Morgen wird es regnen. Auch für Vermutungen: Er wird (wohl) zu Hause sein. 3) Vorgangspassiv: werden + Partizip II: Das Haus wird gebaut. Präteritum wurde gebaut; Perfekt ist gebaut worden — hier heißt das Partizip worden, nicht geworden. Konjugation: ich werde, du wirst, er/sie/es wird, wir/sie werden, ihr werdet; Präteritum wurde. Blocks: A Basistraining → B Vertiefung → C Sprachbausteine → D Wiederholung. Answers in solutions.md.
