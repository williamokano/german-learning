## Übung A3 — Vollverb, Futur oder Passiv?

**Vollverb (etwas werden / sich verändern):** **Im Herbst werden die Tage kürzer.**, **Meine Schwester wird nächsten Monat 18.**, **Nach der Wanderung sind alle müde geworden.**, **Es wird schon spät.**
**Futur (werden + Infinitiv):** **Morgen werde ich dich vom Bahnhof abholen.**, **In zehn Jahren werden viele Autos elektrisch fahren.**, **Das wird schon klappen.**, **Ich werde es mir noch überlegen.**
**Passiv (werden + Partizip II):** **Das Rathaus wird gerade renoviert.**, **Die Pakete werden morgen zugestellt.**, **Der Vertrag wurde gestern unterschrieben.**, **Hier werden Fahrräder repariert.**

## Übung B2 — geworden / worden, Futur / Präsens

1. **b) Es ist kalt geworden.** — Vollverb werden → Perfekt mit sein + geworden.
2. **c) Das Haus ist gebaut worden.** — Vorgangspassiv im Perfekt → ist + Partizip + worden (ohne ge-).
3. **a) Morgen fahre ich nach Köln. / Morgen werde ich nach Köln fahren.** — Bei klarer Zeitangabe reicht das Präsens; Passiv und Vollverb brauchen werden.
4. **c) Eine Vermutung: wahrscheinlich ist er zu Hause.** — werden + Infinitiv kann auch eine Vermutung über die Gegenwart ausdrücken.
5. **a) wurde** — Singular (die Brücke) → wurde + Partizip.
6. **b) wird** — Passiv Präsens / mit Zukunftsbezug → wird + Partizip.
7. **a) abgeschickt worden** — Perfekt-Passiv → Partizip + worden.
8. **b) Der Kaffee wird kalt.** — kalt werden = sich verändern → Vollverb; gebracht werden wäre Passiv, bestellen werden wäre Futur.

# Block C — Prüfungstraining

## Übung C1 — Sprachbausteine Teil 1 — Aus einem Vereinsbrief

1. **c) werden** — Passiv Präsens, Plural (die Zeiten) → werden + Partizip.
2. **b) wird** — Vollverb werden (alt werden), Gegenwart/Zukunft → wird.
3. **c) wurde** — Passiv Präteritum, Singular → wurde + Partizip.
4. **a) kommen werden** — Futur im Nebensatz → Infinitiv + werden am Ende.
5. **c) worden** — Perfekt-Passiv → Partizip + worden.
6. **b) wird** — Vollverb werden (größer werden), Singular → wird.
7. **a) werden** — Passiv Präsens, Plural (Anmeldungen) → werden.
8. **b) wurde** — Passiv Präteritum, unpersönlich → wurde.

# Block D — Wiederholung & Selbsttest

## Übung D1 — Wiederholung: Satzbau

1. Das Fahrrad ist gestern gestohlen worden.
   _Das Fahrrad ist gestern gestohlen worden. (Perfekt-Passiv → worden.)_
2. Nach dem Regen ist es wieder warm geworden.
   _Nach dem Regen ist es wieder warm geworden. (Vollverb → geworden, mit sein.)_
3. Nächste Woche werde ich mit dem Rauchen aufhören.
   _Nächste Woche werde ich mit dem Rauchen aufhören. (Futur.)_
4. Die Ergebnisse werden morgen bekannt gegeben.
   _Die Ergebnisse werden morgen bekannt gegeben. (Passiv Präsens.)_
5. Mein Onkel wurde mit fünfzig noch einmal Vater.
   _Mein Onkel wurde mit fünfzig noch einmal Vater. (Vollverb, Präteritum.)_

## Übung D2 — Selbsttest

1. **c) ist … geworden** — Vollverb werden → sein + geworden.
2. **a) ist … abgeschickt worden** — Perfekt-Passiv → sein + Partizip + worden.
3. **c) wurden** — Plural (die Fenster) → wurden.
4. **a) wird** — werden + Infinitiv drückt hier eine Vermutung aus.
5. **b) Morgen habe ich frei.** — Morgen habe ich frei kommt ohne werden aus (Präsens + Zeitangabe); ein Dach reparieren ist Passiv, dunkel werden ist Vollverb.
6. **a) Vollverb (kalt werden)** — Kein Partizip II, nur ein Adjektiv → Vollverb werden = sich verändern.
