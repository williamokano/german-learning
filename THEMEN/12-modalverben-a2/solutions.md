## Übung B2 — mochte oder wollte? — Bedeutung im Präteritum

1. **a) mochte** — mögen im Präteritum = etwas gern haben/mögen.
2. **b) wollte** — wollen im Präteritum = einen Wunsch/eine Absicht haben.
3. **c) konnte** — können im Präteritum = eine Fähigkeit haben.
4. **a) Durftest** — dürfen im Präteritum = eine Erlaubnis haben.
5. **b) mussten** — müssen im Präteritum = eine Notwendigkeit.
6. **c) sollten** — sollen im Präteritum = die Erwartung einer anderen Person.

# Block C — Prüfungstraining

## Übung C1 — Sprachbausteine Teil 1 — Der erste Arbeitstag

1. **a) musste** — Notwendigkeit → müssen.
2. **b) durfte** — Erlaubnis (negiert) → nicht dürfen.
3. **c) sollte** — Erwartung des Chefs → sollen.
4. **a) konnte** — Fähigkeit → können.
5. **b) wollten** — Bereitschaft/Wunsch → wollen.
6. **c) durfte** — Erlaubnis (negiert) → noch nicht dürfen.
7. **b) musste** — Notwendigkeit → müssen.
8. **a) wollte** — Starker Wunsch → wollen.
