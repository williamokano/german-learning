# Block A — Basistraining

## Übung A1 — sich freuen

|  | sich freuen |
|---|---|
| ich | **mich freue** |
| du | **dich freust** |
| er/sie/es | **sich freut** |
| wir | **uns freuen** |
| ihr | **euch freut** |
| sie/Sie | **sich freuen** |

## Übung A2 — Das richtige Reflexivpronomen

1. **mich**  2. **dich**  3. **sich**  4. **uns**  5. **euch**  6. **sich**

# Block B — Vertiefung

## Übung B1 — Lückentext: Ein stressiger Tag

1. **mich**  2. **mich**  3. **mich**  4. **sich**  5. **uns**  6. **mich**  7. **mich**  8. **mich**

## Übung B2 — Reflexiv oder nicht-reflexiv?

1. **a) mein** — Nicht-reflexiv: waschen + direktes Objekt (das Auto).
2. **b) mich** — Echtes Reflexivverb: sich waschen = sich selbst waschen.
3. **c) meinen** — Nicht-reflexiv: ärgern + Akkusativobjekt (eine andere Person).
4. **a) mich** — Reflexiv: sich ärgern über.
5. **b) meine** — Nicht-reflexiv: interessieren + Akkusativobjekt.
6. **c) mich** — Reflexiv: sich interessieren für.

# Block C — Prüfungstraining

## Übung C1 — Sprachbausteine Teil 1 — Der Morgen einer Familie

1. **a) mich** — sich duschen ist echt reflexiv (Akkusativ).
2. **b) sich** — sich die Zähne putzen: Reflexivpronomen im Dativ (das Akkusativobjekt ist die Zähne).
3. **c) sich** — sich anziehen ist echt reflexiv (Akkusativ).
4. **a) mich** — sich freuen auf: echt reflexiv (Akkusativ).
5. **b) uns** — sich setzen ist echt reflexiv (Akkusativ).
6. **c) sich** — sich interessieren für: echt reflexiv (Akkusativ).
7. **b) uns** — sich beeilen ist echt reflexiv (Akkusativ).
8. **a) mich** — sich erinnern an: echt reflexiv (Akkusativ).
