# so … dass und so ein — A2

Mit so … dass drückt man eine Folge aus: so + Adjektiv oder Adverb im Hauptsatz, dann ein dass-Nebensatz mit dem Verb am Ende. Es war so kalt, dass wir zu Hause blieben. Er spricht so schnell, dass ich nichts verstehe. Auch mit Mengen: Ich habe so viele Termine, dass ich keine Zeit habe. Mit so ein / so eine / so einen + Nomen sagt man solch ein / so etwas wie das — oft als Ausruf: So ein Pech! So ein schönes Haus! So ein- wird wie der unbestimmte Artikel dekliniert (so ein Mann, so eine Frau, so einen Tag). Blocks: A Basistraining → B Vertiefung → C Sprachbausteine → D Wiederholung. Answers in solutions.md.

_5–6 von 6 richtig und alle A/B/C-Übungen sauber gelöst? Merke: so + Adjektiv + , dass = Folge; so ein- + Nomen = solch ein (Artikel-Deklination). Für solch- (dekliniert) und sodass vs. so … dass geht es im B1-Set weiter._
