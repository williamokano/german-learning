# Block A — Basistraining

## Übung A1 — so … dass — Satzbau

1. Der Kaffee war so heiß, dass ich mir den Mund verbrannt habe.
   _Der Kaffee war so heiß, dass ich mir den Mund verbrannt habe._
2. Sie spricht so leise, dass man sie kaum hört.
   _Sie spricht so leise, dass man sie kaum hört._
3. Das Konzert war so laut, dass mir die Ohren wehtaten.
   _Das Konzert war so laut, dass mir die Ohren wehtaten._
4. Ich hatte so viel Arbeit, dass ich das Mittagessen vergessen habe.
   _Ich hatte so viel Arbeit, dass ich das Mittagessen vergessen habe._
5. Der Film war so langweilig, dass wir früher gegangen sind.
   _Der Film war so langweilig, dass wir früher gegangen sind._

## Übung B1 — Lückentext: Ein verrückter Tag

## Übung B2 — so, dass oder so ein?

1. **b) so** — so + Adjektiv (warm) → so.
2. **c) dass** — Folge nach so + Adjektiv → dass.
3. **a) So ein** — so ein + Nomen (das Glück) → So ein.
4. **c) so ein** — das Fahrrad → so ein Fahrrad.
5. **a) so** — so + Adjektiv (schwer) → so.
6. **b) so einem** — mit + Dativ, das Auto → mit so einem Auto.
7. **a) so** — so viele + Nomen … dass → so.
8. **b) So eine** — die Aussicht (feminin) → So eine.

# Block D — Wiederholung & Selbsttest

## Übung D1 — Wiederholung: Satzbau

1. Die Prüfung war so schwer, dass die Hälfte durchgefallen ist.
   _Die Prüfung war so schwer, dass die Hälfte durchgefallen ist._
2. Wir hatten so einen Stau, dass wir den Flug verpasst haben.
   _Wir hatten so einen Stau, dass wir den Flug verpasst haben._
3. So eine Gelegenheit kommt so schnell nicht wieder.
   _So eine Gelegenheit kommt so schnell nicht wieder._
4. Es hat so stark geschneit, dass die Schule ausgefallen ist.
   _Es hat so stark geschneit, dass die Schule ausgefallen ist._

## Übung D2 — Selbsttest

1. **c) so** — so + Adjektiv → so.
2. **a) dass** — Folge nach so + Adjektiv → dass.
3. **c) So einen** — Akkusativ, der Regen → So einen Regen.
4. **a) so eine** — die Wohnung (feminin, Akkusativ) → so eine.
5. **b) so** — so viele + Nomen … dass → so.
6. **a) so einem** — mit + Dativ, der Nachbar → mit so einem Nachbarn.
