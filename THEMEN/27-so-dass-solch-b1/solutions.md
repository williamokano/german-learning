## Übung A1 — solch- deklinieren

| Kontext | Form von solch- |
|---|---|
| ___ Lärm (der, Nominativ) stört mich. | **Solcher** |
| ___ Musik (die, Nominativ) mag ich nicht. | **Solche** |
| ___ Wetter (das, Nominativ) ist selten. | **Solches** |

| Von ___ Angebot (das, Dativ) kann man nur träumen. | **solchem** |

## Übung A2 — solch ein, ein solch- oder solche?

## Übung A3 — sodass oder so … dass?

1. **b) sodass** — Kein so + Adjektiv im Hauptsatz, nur die Folge → sodass.
2. **c) so** — so legt sich um das Adjektiv neblig → so … dass.
3. **a) sodass** — Der Hauptsatz hat schon deutlich; nur die Folge folgt → sodass.
4. **c) so** — so + Adjektiv (schwer) → so … dass.
5. **a) so dass (getrennt)** — sodass und so dass sind beide zulässig; ein Bindestrich ist falsch.
6. **b) sodass** — Kein so + Adjektiv im Hauptsatz → sodass.

## Übung B2 — so … dass ↔ zu … um … zu

1. **a) Das Wasser ist zu kalt, um darin zu schwimmen.** — so … dass … nicht ↔ zu + Adjektiv + um … zu.
2. **b) Der Text ist so lang, dass man ihn nicht in einer Stunde übersetzen kann.** — zu + Adjektiv + um … zu ↔ so … dass … nicht.
3. **c) Sie war so müde, dass sie nicht mehr kochte.** — zu … um … zu drückt aus, dass die Handlung nicht passiert.
4. **b) Die Musik war zu laut, um sich zu unterhalten.** — so … dass … nicht ↔ zu … um … zu.
5. **c) Er reist allein.** — zu … um … zu heißt: die Handlung findet gerade nicht statt.
6. **a) Der Kaffee war so heiß, dass man sich die Zunge verbrennen konnte.** — genug, um … zu ↔ so … dass … können (positiv, die Wirkung ist möglich).

# Block C — Prüfungstraining

## Übung C1 — Sprachbausteine Teil 1 — Aus einer Bewerbung

1. **c) so** — so + Adverb (gut) → so … dass.
2. **b) solchen** — mit + Dativ Plural → solchen Projekten.
3. **a) Solch** — vor ein bleibt solch unflektiert → Solch ein Team.
4. **b) sodass** — reine Folge, kein so + Adjektiv → sodass.
5. **c) solche** — die Freude (feminin, Akkusativ) → solche Freude.
6. **a) so** — so + Adjektiv (vielfältig) → so … dass.
7. **c) solchen** — nach ein wird solch flektiert: einen solchen Aufgabenbereich (Akkusativ).
8. **a) sodass** — Folge ohne so + Adjektiv → sodass.

# Block D — Wiederholung & Selbsttest

## Übung D1 — Wiederholung: Satzbau

1. Der Vortrag war so interessant, dass niemand auf die Uhr geschaut hat.
   _Der Vortrag war so interessant, dass niemand auf die Uhr geschaut hat._
2. Der Referent wurde krank, sodass der Vortrag verschoben werden musste.
   _Der Referent wurde krank, sodass der Vortrag verschoben werden musste._
3. Mit solchen Argumenten überzeugst du niemanden.
   _Mit solchen Argumenten überzeugst du niemanden._
4. Das Angebot war zu gut, um es abzulehnen.
   _Das Angebot war zu gut, um es abzulehnen. (= so gut, dass man es nicht ablehnen konnte.)_

## Übung D2 — Selbsttest

1. **b) Solch** — vor ein bleibt solch unflektiert.
2. **a) solche** — die Geduld (feminin, Akkusativ) → solche.
3. **b) sodass** — reine Folge, kein so + Adjektiv → sodass.
4. **c) so** — so + Adjektiv (heiß) → so … dass.
5. **b) Es ist so spät, dass man nicht mehr anrufen kann.** — zu … um … zu ↔ so … dass … nicht (die Handlung findet nicht statt).
6. **c) solchen** — mit + Dativ Plural → solchen Kollegen.
