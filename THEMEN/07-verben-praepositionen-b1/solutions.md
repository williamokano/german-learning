# Block A — Basistraining

## Übung A1 — Erweiterte Verbliste

|  | Präposition + Fall | Beispiel |
|---|---|---|
| sich interessieren für | **für + Akkusativ** | **Ich interessiere mich für Musik.** |
| sich ärgern über | **über + Akkusativ** | **Ich ärgere mich über den Fehler.** |
| Angst haben vor | **vor + Dativ** | **Ich habe Angst vor Spinnen.** |
| träumen von | **von + Dativ** | **Ich träume von einer Reise.** |
| sich erinnern an | **an + Akkusativ** | **Ich erinnere mich an den Urlaub.** |
| teilnehmen an | **an + Dativ** | **Ich nehme an dem Kurs teil.** |

## Übung A2 — wovor/davor, wovon/davon

1. **Wovor**  2. **Wovon**  3. **dafür**  4. **darüber**  5. **davor**  6. **davon**

1. **a) daran** — denken an → daran.
2. **b) davon** — träumen von → davon.
3. **b) davor** — Angst haben vor → davor.
4. **a) darüber** — sprechen über → darüber.
5. **b) dafür** — sich interessieren für → dafür.
6. **b) darauf** — warten auf → darauf.
