## Übung B2 — mich/dich oder mir/dir?

1. **a) mich** — Kein Akkusativobjekt → Reflexivpronomen im Akkusativ.
2. **b) mir** — die Hände ist das Akkusativobjekt → Reflexivpronomen im Dativ.
3. **c) dich** — Kein Akkusativobjekt → Reflexivpronomen im Akkusativ.
4. **a) dir** — die Haare ist das Akkusativobjekt → Reflexivpronomen im Dativ.
5. **b) sich** — Kein Akkusativobjekt → Reflexivpronomen im Akkusativ (sich für er/sie/es).
6. **c) sich** — das Gesicht ist das Akkusativobjekt → sich bleibt gleich (er/sie/es hat keine eigene Dativform).

# Block C — Prüfungstraining

## Übung C1 — Sprachbausteine Teil 1 — Vor der Party

1. **a) mich** — Kein Objekt → Akkusativ.
2. **b) mir** — die Augen ist das Objekt → Dativ.
3. **c) sich** — Kein Objekt → sich (Akkusativ).
4. **a) sich** — das Kleid ist das Objekt → sich bleibt gleich (Dativ).
5. **b) dich** — Kein Objekt → Akkusativ.
6. **c) dir** — die Haare ist das Objekt → Dativ.
7. **b) uns** — Kein Objekt → Akkusativ (uns bleibt gleich).
8. **a) uns** — die Schuhe ist das Objekt → uns bleibt gleich (Dativ).
