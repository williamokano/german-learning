# Block B — Vertiefung

## Übung B1 — Lückentext: Meine Kindheit

1. **spielte**  2. **hatte**  3. **gingen**  4. **kochte**  5. **las**  6. **blieb**  7. **dachten**  8. **kamen**

## Übung B2 — Der Vokalwechsel bei starken Verben

1. **a) fuhr** — fahren: starkes Verb → fuhr, kein -te.
2. **b) sahst** — sehen: starkes Verb → sahst.
3. **c) aß** — essen: starkes Verb → aß, kein -te und keine Endung in er/sie/es.
4. **b) tranken** — trinken: starkes Verb → tranken.
5. **c) schriebt** — schreiben: starkes Verb → schriebt.
6. **b) sprachen** — sprechen: starkes Verb → sprachen.

# Block C — Prüfungstraining

## Übung C1 — Sprachbausteine Teil 1 — Ein Märchen

1. **a) war** — es war einmal: die klassische Märchenformel.
2. **a) wohnte** — wohnen: schwaches Verb → wohnte.
3. **b) ging** — gehen: starkes Verb → ging.
4. **a) traf** — treffen: starkes Verb → traf.
5. **c) war** — Zustand → war.
6. **a) hatte** — Angst haben → hatte.
7. **b) kam** — kommen: starkes Verb → kam.
8. **b) wurde** — es wurde gut: Veränderung/Ergebnis → wurde.
