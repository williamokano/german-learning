# Modalverben: Präsens und Bedeutung — A1

Standalone drill set, not tied to any lesson. The six modal verbs — können, müssen, wollen, sollen, dürfen, möchten (from mögen) — are all irregular in the singular (ich/er-sie-es have no ending and often a different vowel: ich kann, not ich könne) and always push the main verb to the end as a bare infinitive: Ich kann gut schwimmen. This set drills the forms first, then the meaning differences: können = ability, müssen = necessity, dürfen = permission, wollen = desire, sollen = someone else's expectation, möchten = a polite want. Blocks: A Basistraining → B Vertiefung → C Sprachbausteine → D Wiederholung. Answers in solutions.md.
