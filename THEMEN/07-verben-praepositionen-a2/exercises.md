# Verben mit fester Präposition: warten auf, sich freuen, denken an … — A2

Standalone drill set, not tied to any lesson. Many German verbs pair with a fixed preposition whose meaning you can't guess (warten AUF, denken AN, sich freuen AUF for something ahead vs. ÜBER for something that already happened). To ask or refer back to a THING, use a wo-/da-compound (worauf/darauf, woran/daran, worüber/darüber). For a PERSON, never use these compounds — use preposition + wen/wem in the question and preposition + pronoun in the answer (auf wen? — auf ihn). Blocks: A Basistraining → B Vertiefung → C Sprachbausteine → D Wiederholung. Answers in solutions.md.
