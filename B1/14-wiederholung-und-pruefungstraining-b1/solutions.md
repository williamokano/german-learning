## Übung B10 — Sprachbausteine — B1/10 Zweiteilige Konnektoren

1. **b) sowohl … als auch** — 'sowohl … als auch' (both … and) expresses that both options are true simultaneously.
2. **c) weder … noch** — 'weder … noch' (neither … nor) negates both elements.
3. **a) zwar … aber** — 'zwar … aber' (admittedly … but) expresses concession.
4. **b) entweder … oder** — 'entweder … oder' (either … or) presents two alternatives.
5. **a) nicht nur … sondern auch** — 'nicht nur … sondern auch' (not only … but also) adds emphasis to the second element.

## Übung D2 — Wortschatz-Check: Das passt nicht! (B1-Wiederholung)

1. ~~die Miete~~ — "die Miete" (rent) is a housing term, not an exam/language learning term.
2. ~~Hey, wie geht es dir?~~ — "Hey, wie geht es dir?" is informal — all others are formal email phrases.
3. ~~weil~~ — "weil" (because) expresses cause; the others (obwohl, trotzdem, zwar…aber) all express concession or contrast.
4. ~~womit~~ — "womit" is an interrogative Pronominaladverb (wo-form); the others are da-forms used in statements.
5. ~~das Passiv~~ — "das Passiv" is a grammar term; the others are nominalizations derived from verbs.
6. ~~wegen … trotz~~ — "wegen … trotz" is not a pair of correlative connectors; the others are genuine zweiteilige Konnektoren.
