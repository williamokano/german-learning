# Block A — Basistraining

## Übung A1 — je … desto

1. Je mehr ich lerne, desto besser verstehe ich es.
   _Je mehr ich lerne, desto besser verstehe ich es._
2. Je älter man wird, desto weiser wird man.
   _Je älter man wird, desto weiser wird man._
3. Je schneller du arbeitest, desto früher bist du fertig.
   _Je schneller du arbeitest, desto früher bist du fertig._
4. Je mehr Geld er verdient, desto mehr gibt er aus.
   _Je mehr Geld er verdient, desto mehr gibt er aus._
5. Je länger die Reise dauert, desto müder werden wir.
   _Je länger die Reise dauert, desto müder werden wir._
6. Je später es wird, desto ruhiger wird die Stadt.
   _Je später es wird, desto ruhiger wird die Stadt._

## Übung A2 — indem (Methode) oder sodass (Folge)?

## Übung B2 — es sei denn: Verb-Zweit, nicht Nebensatz

1. **a) es regnet** — Verb-Zweit, nicht Nebensatz → es regnet.
2. **b) ich bin krank** — Verb-Zweit → ich bin krank.
3. **b) unless / außer wenn** — es sei denn = unless / außer wenn.
4. **c) der Preis ist zu hoch** — Verb-Zweit → der Preis ist zu hoch.
5. **a) jemand ruft sie an** — Verb-Zweit → jemand ruft sie an.
6. **b) es gibt keinen Parkplatz** — Verb-Zweit → es gibt keinen Parkplatz.
