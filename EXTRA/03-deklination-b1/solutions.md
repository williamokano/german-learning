# Block A — Basistraining

## Übung A1 — Stark vs. schwach: der Mann, der Junge, der Student

|  | der Mann (stark) | der Junge (schwach) | der Student (schwach) |
|---|---|---|---|
| Nom. | **der Mann** | **der Junge** | **der Student** |
| Akk. | **den Mann** | **den Jungen** | **den Studenten** |
| Dat. | **dem Mann** | **dem Jungen** | **dem Studenten** |
| Gen. | **des Mannes** | **des Jungen** | **des Studenten** |

1. **a) Wegen** — Der Streik ist der Grund → wegen.
2. **b) Während** — Zeitraum → während.
3. **b) Trotz** — Gegensatz (schlechtes Wetter, aber wir spielen trotzdem draußen) → trotz.
4. **a) statt** — Ersatz (Tee anstelle von Kaffee) → statt.
5. **a) Wegen** — Grund → wegen.
6. **c) Trotz** — Gegensatz (Lärm, aber ich konnte trotzdem schlafen) → trotz.

# Block C — Prüfungstraining

## Übung C1 — Sprachbausteine Teil 1 — Beim Bäcker

1. **b) den Kunden** — begrüßen + Akkusativ, schwacher Nomen → den Kunden.
2. **b) dem Kunden** — zeigen + Dativ, schwacher Nomen → dem Kunden.
3. **b) des** — Genitiv maskulin → des.
4. **b) den Jungen** — kennen + Akkusativ, schwacher Nomen → den Jungen.
5. **b) dem Jungen** — geben + Dativ, schwacher Nomen → dem Jungen.
6. **b) des** — Genitiv maskulin → des.
7. **a) der** — Genitiv Plural → der.
8. **b) den Kunden** — danken + Dativ Plural, schwacher Nomen → den Kunden.

1. **b) den** — kennen + Akkusativ; Herr ist ein schwacher Nomen → den Herrn.

3. **a) Wegen** — Grund → Wegen.
