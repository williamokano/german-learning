# Block A — Basistraining

## Übung A1 — Gegenwart (Infinitiv I) und Vergangenheit (Infinitiv II)

|  | Gegenwart (Infinitiv I) | Vergangenheit (Infinitiv II) |
|---|---|---|
| müssen (starke Vermutung) | **Er muss krank sein.** | **Er muss krank gewesen sein.** |
| sollen (Gerücht) | **Er soll reich sein.** | **Er soll reich gewesen sein.** |
| können (Möglichkeit) | **Er kann Recht haben.** | **Er kann Recht gehabt haben.** |

## Übung B2 — Objektiv oder subjektiv? — Welches Modalverb passt?

1. **a) muss** — Starke Vermutung → müssen.
2. **b) soll** — Gerücht → sollen.
3. **c) könnte** — Möglichkeit → können/könnte.
4. **a) will** — Bezweifelte Behauptung → wollen.
5. **b) kann** — Unmöglichkeit → nicht können.
6. **c) dürfte** — Vorsichtige Vermutung → dürfte.
