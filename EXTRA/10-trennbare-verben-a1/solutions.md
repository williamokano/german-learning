# Trennbare und untrennbare Verben — A1

---

# Block A — Basistraining

## Übung A1 — Trennbar oder untrennbar?

**trennbar:** **aufstehen**, **einkaufen**, **anrufen**, **mitkommen**, **aufräumen**
**untrennbar:** **verstehen**, **bezahlen**, **erklären**, **besuchen**, **verkaufen**

## Übung A2 — Das trennbare Präfix ans Satzende

1. **auf**  2. **ein**  3. **an**  4. **auf**  5. **mit**  6. **los**

# Block B — Vertiefung

## Übung B1 — Lückentext: Ein Tag im Leben

1. **auf**  2. **auf**  3. **ein**  4. **an**  5. **ab**  6. **fern**  7. **auf**  8. **aus**

## Übung B2 — Wie sagt man richtig?

1. **b) Ich stehe früh auf.** — aufstehen: trennbar → Präfix ans Satzende.
2. **c) Ich verstehe das nicht.** — verstehen: untrennbar, bleibt immer zusammen.
3. **a) Wir kaufen Obst ein.** — einkaufen: trennbar → Präfix ans Satzende.
4. **a) Sie besucht mich morgen.** — besuchen: untrennbar, bleibt immer zusammen.
5. **b) Ruf mich bitte an!** — anrufen: trennbar → Präfix ans Satzende.
6. **a) Er bezahlt die Rechnung.** — bezahlen: untrennbar, bleibt immer zusammen.

# Block C — Prüfungstraining

## Übung C1 — Sprachbausteine Teil 1 — Trennbare Präfixe

1. **a) auf** — aufmachen.
2. **b) auf** — aufräumen.
3. **b) ein** — einkaufen.
4. **b) an** — anrufen.
5. **a) an** — ankommen.
6. **c) ab** — abholen.
7. **c) fern** — fernsehen.

# Block D — Wiederholung & Selbsttest

## Übung D1 — Gemischte Wiederholung

1. **auf**  2. **ein**  3. **an**  4. **mit**  5. **ab**  6. **zu**

## Übung D2 — Selbsttest

1. **a) Ich stehe um sechs auf.** — aufstehen: trennbar → Präfix ans Satzende.
2. **b) Wir besuchen dich morgen.** — besuchen: untrennbar, bleibt immer zusammen.
3. **c) Er kauft Milch ein.** — einkaufen: trennbar → Präfix ans Satzende.
4. **b) Sie erklärt mir die Regel.** — erklären: untrennbar, bleibt immer zusammen.
5. **c) Mach die Tür zu!** — zumachen: trennbar → Präfix ans Satzende.
6. **a) Ich verkaufe mein altes Auto.** — verkaufen: untrennbar, bleibt immer zusammen.
