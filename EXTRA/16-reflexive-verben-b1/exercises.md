# Reflexive Verben: Akkusativ- und Dativ-Reflexiv — B1

Standalone drill set, not tied to any lesson. The same reflexive verb can take an Akkusativ or a Dativ reflexive pronoun depending on whether there's already an Akkusativ object in the sentence: Ich wasche MICH (no object → Akkusativ) vs. Ich wasche MIR die Hände (die Hände is the Akkusativ object, so the reflexive pronoun shifts to Dativ). The distinction only really shows up for ich/du (mich/mir, dich/dir) — er/sie/es, wir, ihr, and sie/Sie use sich/uns/euch either way, since those forms are identical in both cases. Blocks: A Basistraining → B Vertiefung → C Sprachbausteine → D Wiederholung. Answers in solutions.md.
