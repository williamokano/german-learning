# Block B — Vertiefung

## Übung B1 — Lückentext: Ein Tag im Büro

1. **muss**  2. **muss**  3. **soll**  4. **darf**  5. **kann**  6. **möchte**  7. **muss**  8. **kann**

## Übung B2 — Welche Bedeutung passt?

1. **a) darf** — Verbot → nicht dürfen.
2. **b) muss** — Notwendigkeit → müssen.
3. **c) Kannst** — Höfliche Bitte → können.
4. **a) sollen** — Erwartung einer anderen Person → sollen.
5. **b) will** — Starker Wunsch → wollen.
6. **c) Darf** — Erlaubnis erfragen → dürfen.

# Block C — Prüfungstraining

## Übung C1 — Sprachbausteine Teil 1 — Regeln in der Schule

1. **a) muss** — Regel → müssen.
2. **b) dürfen** — Verbot → nicht dürfen.
3. **c) Darf** — Erlaubnis erfragen → dürfen.
4. **a) sollen** — Erwartung der Lehrerin → sollen.
5. **b) kann** — Fähigkeit → können.
6. **c) müssen** — müssen nicht = keine Notwendigkeit.
7. **b) will** — Starker Wunsch → wollen.
8. **a) Kannst** — Bitte → können.
