# Block B — Vertiefung

## Übung B1 — Lückentext: Die Lehrerin (Dativ Plural)

1. **den Schülern**  2. **den Kindern**  3. **den Stunden**  4. **den Eltern**  5. **den Freunden**  6. **den Kollegen**  7. **den Nachbarn**  8. **den Eltern**

## Übung B2 — Genitiv-Vorschau: des, der, des, der

1. **b) des** — Genitiv maskulin → des; das Nomen bekommt -s (Lehrers).
2. **a) der** — Genitiv feminin → der; das Nomen bleibt unverändert.
3. **a) des** — Genitiv neutrum → des; Kind bekommt -es (leichter auszusprechen als Kinds).
4. **c) der** — Genitiv Plural → der.
5. **a) des** — Genitiv neutrum → des; Buch bekommt -es.
6. **a) des** — Genitiv neutrum → des; Auto bekommt nur -s (endet schon auf Vokal).

## Übung D2 — Selbsttest

1. **c) Das** — Nominativ neutrum → Das.
2. **a) ein** — Akkusativ neutrum → ein.
3. **b) dem** — mit + Dativ maskulin → dem.
4. **b) des** — Genitiv maskulin → des (Nachbar ist ein schwacher Nomen: des Nachbarn).
