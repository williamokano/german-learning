# Verben mit fester Präposition: warten auf, sich freuen, denken an … — A2

---

# Block A — Basistraining

## Übung A1 — Verb + Präposition + Fall

|  | Präposition + Fall | Beispiel |
|---|---|---|
| warten | **auf + Akkusativ** | **Ich warte auf den Bus.** |
| sich freuen (Zukunft) | **auf + Akkusativ** | **Ich freue mich auf die Ferien.** |
| sich freuen (Vergangenheit) | **über + Akkusativ** | **Ich freue mich über das Geschenk.** |
| denken | **an + Akkusativ** | **Ich denke an dich.** |
| sprechen | **über + Akkusativ** | **Wir sprechen über das Wetter.** |

## Übung A2 — wo(r)- für Sachen, Präposition + wen/wem für Personen

1. **Worauf**  2. **Auf wen**  3. **Woran**  4. **An wen**  5. **Worüber**  6. **Über wen**

# Block B — Vertiefung

## Übung B1 — Lückentext: Unser Wochenende

1. **auf**  2. **auf**  3. **über**  4. **an**  5. **über**  6. **auf**  7. **an**  8. **über**

## Übung B2 — da(r)-Kompositum (Sache) oder Präposition + Pronomen (Person)?

1. **a) darauf** — Sache → darauf.
2. **b) auf sie** — Person → auf sie (nicht darauf).
3. **a) daran** — Sache → daran.
4. **b) an ihn** — Person → an ihn.
5. **a) darüber** — Sache → darüber.
6. **b) über sie** — Person → über sie.
