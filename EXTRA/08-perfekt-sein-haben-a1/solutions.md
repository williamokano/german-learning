## Übung B2 — Welches Hilfsverb passt?

1. **b) habe** — kaufen: kein Bewegungsverb → haben.
2. **b) ist** — fahren: Bewegungsverb → sein.
3. **b) haben** — arbeiten: kein Bewegungsverb → haben.
4. **a) aufgewacht** — Partizip II von aufwachen → aufgewacht (schwaches Verb: ge-…-t).
5. **c) sind** — kommen: Bewegungsverb, Plural → sind.
6. **b) habe** — öffnen: kein Bewegungsverb → haben.

# Block C — Prüfungstraining

## Übung C1 — Sprachbausteine Teil 1 — Ein Ausflug

1. **a) haben** — machen → haben.
2. **b) sind** — fahren → sein.
3. **c) haben** — besuchen → haben.
4. **a) habe** — essen → haben.
5. **c) hat** — machen → haben.
6. **a) sind** — kommen → sein.
7. **b) bin** — einschlafen: Zustandswechsel → sein.
8. **c) ist** — sein → sein (Ausnahme, immer sein als Hilfsverb).
