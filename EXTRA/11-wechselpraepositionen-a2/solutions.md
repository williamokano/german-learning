# Block A — Basistraining

## Übung A1 — Wo? (Dativ) vs. Wohin? (Akkusativ)

|  | Wo? (Dativ) | Wohin? (Akkusativ) |
|---|---|---|
| in / der Park | **im Park** | **in den Park** |
| an / die Wand | **an der Wand** | **an die Wand** |
| auf / der Tisch | **auf dem Tisch** | **auf den Tisch** |
| unter / das Bett | **unter dem Bett** | **unter das Bett** |
| vor / die Tür | **vor der Tür** | **vor die Tür** |
| zwischen / die Bücher | **zwischen den Büchern** | **zwischen die Bücher** |

## Übung A2 — Wo oder wohin?

1. **in der**  2. **in die**  3. **an der**  4. **an die**  5. **auf dem**  6. **auf den**

1. **a) unter dem Bett** — stehen (Zustand, Wo?) → Dativ.
