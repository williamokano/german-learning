## Übung exam-S9 — Aufgabe 9 — Stellungnahme (Forumsbeitrag)

Schreiben Sie eine Stellungnahme (ca. 150–180 Wörter) als Forumsbeitrag.

**Your task:** In einem Online-Forum haben Sie folgenden Beitrag gelesen:

„Herkunftssprachen wie Türkisch oder Arabisch an deutschen Schulen zu
fördern, ist reine Geldverschwendung. Die Kinder leben hier, also sollen
sie gefälligst Deutsch lernen — alles andere ist Privatsache der Familien.
— kritischer_Buerger"

Schreiben Sie eine sachliche Stellungnahme. Gehen Sie auf folgende Punkte ein:
- Wie stehen Sie zu der Aussage? Stimmen Sie zu oder widersprechen Sie?
- Welche Vorteile könnte die Förderung von Herkunftssprachen haben?
- Welchen Einwand können Sie nachvollziehen, und wie entkräften Sie ihn?

Formulieren Sie unpersönlich und vorsichtig (Hedging), räumen Sie einen
Gegenpunkt ein (Konzession) und vermeiden Sie Killerphrasen.


Use:
- [ ] Eine klare Positionierung („Meiner Ansicht nach …", „Ich vertrete den Standpunkt, dass …")
- [ ] Mindestens ein Argument mit Begründung oder Beleg
- [ ] Eine Konzession (Da ist zwar … recht, dennoch …)
- [ ] Hedging an mindestens einer Stelle (dürfte, deutet darauf hin, tendenziell)
- [ ] Ein abschließender Satz („Insgesamt lässt sich festhalten, dass …")

Self-check:
- [ ] Ist meine Position klar und begründet, nicht nur behauptet?
- [ ] Habe ich einen Gegenpunkt eingeräumt, bevor ich ihn entkräfte?
- [ ] Habe ich starke Behauptungen mit Hedging abgefedert?
- [ ] Habe ich jede Killerphrase und jedes umgangssprachliche Wort vermieden?
- [ ] Ist der Beitrag zwischen 150 und 180 Wörter lang?

## Übung exam-Sp11 — Aufgabe 11 — Sprechen (2 Teile)

Führen Sie beide Sprechaufgaben durch — mit einem Partner oder als Monolog (Aufnahme). Bewerten Sie sich anschließend selbst anhand der Kriterien.

**Teil 4a — Vortrag (ca. 3–4 Minuten)**

Ziehen Sie ein Thema und halten Sie einen kurzen, strukturierten Vortrag. Beginnen Sie mit einer rhetorischen Frage, kündigen Sie Ihre Gliederung an und schließen Sie mit einer Zusammenfassung.

- Thema 1: Sollten Herkunftssprachen an Schulen gefördert werden?
- Thema 2: Verändert die künstliche Intelligenz das Lernen zum Guten?
- Thema 3: Sollte an Universitäten mehr auf Englisch gelehrt werden?
- Struktur: Einstieg (rhetorische Frage) → Gliederung ankündigen → Pro → Contra → Fazit
- Verwenden Sie: Zunächst … anschließend … abschließend …; Damit komme ich zu …
- Verwenden Sie Hedging: Es deutet einiges darauf hin, dass …; … dürfte … sein
- Verwenden Sie ein rhetorisches Mittel (rhetorische Frage, Dreierfigur)

**Teil 4b — Diskussion (ca. 4–5 Minuten)**

Diskutieren Sie mit Ihrem Partner über das Thema Ihres Vortrags. Vertreten Sie Ihre Position, gehen Sie auf Einwände ein und versuchen Sie, zu einem gemeinsamen Fazit zu kommen.

- Stimmen Sie zu oder widersprechen Sie: Dem kann ich nur zustimmen … / Da würde ich widersprechen …
- Räumen Sie ein und widersprechen Sie diplomatisch: Da haben Sie zwar recht, dennoch …
- Reagieren Sie auf Argumente: Wie meinen Sie das genau? / Man könnte einwenden, dass …
- Vermeiden Sie Killerphrasen (kein „Das ist Unsinn")
- Verwenden Sie C1-Konnektoren: zumal, sofern, insofern, einerseits … andererseits
- Fassen Sie am Ende einen Konsens zusammen: Wir sind uns also einig, dass …

**Bewertungskriterien:**
- 4a — Struktur erkennbar (Einstieg → Gliederung → Pro → Contra → Fazit): stark 2 Pkt. / ausreichend 1 Pkt. / schwach 0 Pkt.
- 4a — Gliederungssignale und Übergänge korrekt verwendet: stark / ausreichend / schwach
- 4a — Mindestens ein rhetorisches Mittel sinnvoll eingesetzt: stark / ausreichend / schwach
- 4a — Hedging / vorsichtiges Formulieren: stark / ausreichend / schwach
- 4a — Flüssigkeit, Tempo und Pausen: stark / ausreichend / schwach
- 4b — Eigene Position klar vertreten und begründet: stark / ausreichend / schwach
- 4b — Diplomatisch widersprochen und eingeräumt (keine Killerphrasen): stark / ausreichend / schwach
- 4b — Auf den Partner reagiert und einen Konsens gesucht: stark / ausreichend / schwach
- 4b — C1-Konnektoren korrekt verwendet: stark / ausreichend / schwach
- Gesamt Sprechen: BESTANDEN = in beiden Teilen mindestens „ausreichend"
