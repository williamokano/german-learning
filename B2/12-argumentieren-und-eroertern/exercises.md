## Übung B1 — Architektur einer Erörterung entwerfen

> Du hast in der Zeitung einen Artikel gelesen, der autofreie Innenstädte ablehnt.
Der Autor nennt allerdings keine Belege. Du willst eine eigene Erörterung schreiben.


**Your task:** Schreib zu folgendem Thema eine vollständige Erörterung (180–220 Wörter): „Sollte es in Städten autofreie Innenstädte geben?". Halte dich an die Architektur: Einleitung mit These, Hauptteil mit Pro-Argumenten + wichtigstem Contra + Widerlegung, Schluss mit Fazit.

Use:
- [ ] 1 klare These in der Einleitung (mit „Ich bin der Ansicht, dass …" oder „Meiner Meinung nach …")
- [ ] mindestens 2 Pro-Argumente mit Beleg oder Beispiel
- [ ] 1 wichtigstes Contra-Argument mit Widerlegung („Diesem Argument ist entgegenzuhalten, dass …")
- [ ] 1 Fazit im Schluss („Zusammenfassend lässt sich sagen, dass …")
- [ ] (B1/10) mindestens 1 zweiteiliger Konnektor (nicht nur … sondern auch / zwar … aber / weder … noch …)
- [ ] (B2/07) mindestens 1 Konnektor aus B2/07 (obwohl / dennoch / je … desto / indem / sofern)

Self-check:
- [ ] Habe ich in der Einleitung eine klare These formuliert (nur eine Meinung, keine Pro-Contra-Liste)?
- [ ] Hat jedes Argument einen Beleg oder ein Beispiel?
- [ ] Habe ich das wichtigste Contra-Argument nicht nur genannt, sondern auch widerlegt?
- [ ] Steht im Schluss ein Fazit ohne neue Argumente?
- [ ] Stimmen die zweiteiligen Konnektoren (beide Teile, Komma vor dem zweiten Teil)?
