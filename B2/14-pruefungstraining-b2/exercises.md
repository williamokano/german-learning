— Markus_Kr"

Schreiben Sie eine ausführliche Antwort auf diesen Beitrag. Gehen Sie auf
folgende Punkte ein:
- Stimmen Sie Markus zu, oder haben Sie eine andere Meinung?
- Welche Vorteile und welche Nachteile hat das Homeoffice Ihrer Erfahrung nach?
- Wie sollte Ihrer Meinung nach eine moderne Arbeitswelt aussehen?

Verwenden Sie Konjunktiv I (indirekte Rede), Passiv-Alternativen
(sich lassen / -bar / man) und mindestens zwei B2-Konnektoren
(einerseits … andererseits, zwar … aber, nicht nur … sondern auch …).


Use:
- [ ] Klare Meinungsäußerung mit „Meiner Meinung nach …" oder „Ich bin der Überzeugung, dass …"
- [ ] Mindestens ein Vorteil von Homeoffice
- [ ] Mindestens ein Nachteil von Homeoffice
- [ ] Ein B2-Konnektor (einerseits … andererseits / zwar … aber / nicht nur … sondern auch)
- [ ] Mindestens eine Passiv-Alternative (sich lassen / -bar / man)

## Übung exam-Sp11 — Aufgabe 11 — Sprechen (3 Teile)

Führen Sie alle drei Sprechaufgaben durch — mit einem Partner oder als Monolog (Aufnahme). Bewerten Sie sich anschließend selbst anhand der Kriterien.

**Teil 4a — Sich vorstellen (ca. 2 Minuten)**

Stellen Sie sich vor und sprechen Sie über die folgenden Punkte.

- 1. Name und Alter
- 2. Herkunft und Wohnort
- 3. Beruf oder Studium
- 4. Sprachen
- 5. Ein Hobby oder Interesse
- 6. Warum Sie Deutsch lernen

**Teil 4b — Über ein Thema sprechen (ca. 3 Minuten)**

Sie ziehen ein Thema und halten eine kurze Präsentation. Verwenden Sie Konjunktiv II für Hypothesen, Konnektoren für Übergänge und mindestens ein Partizipialattribut.

- Thema 1: Sollte Homeoffice zur Regel werden?
- Thema 2: Brauchen wir eine Frauenquote in Unternehmen?
- Thema 3: Wie verändert die Digitalisierung unser Leben?
- Struktur: Einleitung → Pro-Argumente → Contra-Argumente → Fazit
- Verwenden Sie: einerseits … andererseits, zwar … aber, nicht nur … sondern auch, meiner Meinung nach, insgesamt lässt sich sagen
- Verwenden Sie: Wenn ich … wäre / hätte, würde ich … (Konjunktiv II)
- Verwenden Sie: ein Partizipialattribut, z. B. „die im Jahr 2020 eingeführte Regelung"

**Teil 4c — Gemeinsam planen / diskutieren (ca. 4 Minuten)**

Planen Sie gemeinsam mit Ihrem Partner eine Veranstaltung zum Thema „Sprachen lernen in unserer Stadt". Verwenden Sie Konjunktiv I (indirekte Rede), Funktionsverbgefüge und Konnektoren.

- Was? (z. B. Sprachcafé, Workshop, Vortrag)
- Für wen? (Zielgruppe)
- Wann und wo? (Termin, Ort)
- Wer macht was? (Aufgabenverteilung)
- Wie wird es beworben? (Kommunikation)
- Verwenden Sie Konjunktiv I: Die Stadtverwaltung habe zugesagt, dass …
- Verwenden Sie Funktionsverbgefüge: Wir sollten eine Entscheidung treffen / Bezug nehmen auf …
- Verwenden Sie Konnektoren für Übergänge und Konsens

**Bewertungskriterien:**
- 4a — Inhalt (alle 6 Punkte angesprochen): stark 2 Pkt. / ausreichend 1 Pkt. / schwach 0 Pkt.
- 4a — Flüssigkeit: stark 2 Pkt. / ausreichend 1 Pkt. / schwach 0 Pkt.
- 4a — Aussprache und Intonation: stark 2 Pkt. / ausreichend 1 Pkt. / schwach 0 Pkt.
- 4b — Struktur erkennbar (Einleitung → Pro → Contra → Fazit): stark / ausreichend / schwach
- 4b — Mindestens 3 Konnektoren korrekt verwendet: stark / ausreichend / schwach
- 4b — Konjunktiv II für Hypothesen korrekt: stark / ausreichend / schwach
- 4b — Mindestens ein Partizipialattribut korrekt: stark / ausreichend / schwach
- 4c — Alle 5 Planungspunkte besprochen: stark / ausreichend / schwach
- 4c — Konjunktiv I korrekt verwendet: stark / ausreichend / schwach
- 4c — Reaktion auf den Partner / Konsens finden: stark / ausreichend / schwach
- Gesamt Sprechen: BESTANDEN = in jedem der 3 Teile mindestens „ausreichend"
