## Übung A3 — Partizip I oder Partizip II?

1. **a) lachende** — Das Kind lacht selbst → aktiv → Partizip I: das lachende Kind.
2. **b) gekochte** — Das Ei wurde gekocht → passiv → Partizip II: das gekochte Ei.
3. **b) gegründete** — Die Firma wurde gegründet → passiv → Partizip II.
4. **a) steigende** — Die Nachfrage steigt selbst, gerade jetzt → aktiv → Partizip I.
5. **b) angekommene** — Abgeschlossen, „sein"-Perfekt → Partizip II: der angekommene Zug.
6. **b) eröffnete** — Sie wurde eröffnet → passiv → Partizip II.

## Übung A11 — Welche Endung ist richtig?

4. **a) verkauften** — Plural → -en: die verkauften Werke.
5. **b) schreienden** — Dativ → -en: dem schreienden Baby.
