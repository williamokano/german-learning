# HOEREN — Standalone Listening-Comprehension Sets

This directory holds **listening-comprehension batteries that are not part of
the A1→C1 curriculum**. Each set is a handful of longer, level-appropriate
audio passages (Anrufbeantworter-Nachrichten, Durchsagen, kurze Vorträge) with
comprehension questions — the skill (Hörverstehen) that's otherwise only
tested inside a few Hören blocks (H1–H4) scattered across individual
curriculum lessons, never as its own standalone practice surface.

They reuse the same exercise engine as everything else
(`exercises.yml` → generated `exercises.md`/`solutions.md`), and the same
`audio`/`transcript` mechanism already used by curriculum H4 exercises
(see e.g. `A1/01-erste-kontakte/exercises.yml`, id `H4`) — nothing new on the
schema or generation side.

## Where they live on the site

Served at `/hoeren/<dir-slug>/uebungen/`, same `[level]/[lesson]/uebungen.astro`
route THEMEN/SITUATIONEN use. `/hoeren/` lists every set grouped by topic.

## File layout and naming

```
HOEREN/<NN>-<topic-slug>-<level>/
├── exercises.yml   # hand-authored source (transcript text goes here)
├── exercises.md    # generated — npx tsx build/gen-exercises.ts HOEREN/<dir>
├── solutions.md    # generated
└── audio/          # generated by scripts/generate_audio.py — NOT hand-authored
```

`lesson:` uses the `HV/<dir-slug>` shape (Hörverstehen), the sibling prefix to
THEMEN's `EX/` and SITUATIONEN's `SIT/` — see `web/src/core/content/schema.ts`.

## Authoring a set (text first, audio later)

Each listening passage is one `H`-block `single-choice` exercise: a full
monologue in `transcript:` (voicemail, announcement, short talk — **mono**
speaker only, matching the existing H4 "Ansage" convention; no multi-speaker
dialog support in the audio pipeline yet), an `audio:` filename following the
`transcript_ansage<N>.mp3` pattern (the number is how `scripts/generate_audio.py`
and the markdown renderer find/label the block — see `build/gen-exercises.ts`'s
`renderTranscriptBlock`), and 2–4 `items[]` comprehension questions about it.

1. Write the transcript and comprehension questions in `exercises.yml` —
   the content is fully reviewable and playable-in-your-head before any
   audio exists (the `<details>` transcript spoiler works with or without
   a real MP3 behind the `audio:` link).
2. `npx tsx build/gen-exercises.ts HOEREN/<dir>` to generate the `.md` files.
3. `npx tsx build/gen-exercises.ts --all --check` to confirm no drift.
4. Run the manual answer-substitution read-through and the check-*.ts
   authoring aids, same discipline as THEMEN/SITUATIONEN (see their READMEs).
5. Commit the text-only PR. **Audio generation is a separate step** — see
   "Generating the audio" below — because it needs an `ELEVEN_API_KEY` and
   real API spend, which isn't always available in the environment doing the
   authoring.

## Generating the audio

Requires an ElevenLabs API key (see root `README.md` → "Regenerating audio"
for setup). Once you have `ELEVEN_API_KEY` exported:

```bash
# Generate every missing MP3 across the whole repo, HOEREN/ included —
# the script already discovers HOEREN/*/exercises.md via a recursive glob,
# no extra flag needed:
python3 scripts/generate_audio.py --all

# Or target just one HOEREN set:
python3 scripts/generate_audio.py HOEREN/01-anrufbeantworter-a2/exercises.md
python3 scripts/generate_audio.py HOEREN/02-durchsagen-b1/exercises.md
python3 scripts/generate_audio.py HOEREN/03-kurzvortraege-b2/exercises.md
```

The script writes MP3s to `HOEREN/<dir>/audio/*.mp3` (sibling of
`exercises.md`, same convention as every curriculum lesson) and rewrites the
🎧 audio-reference line in `exercises.md` in place. After that:

```bash
cd web && npm run build   # runs mirror-audio.mjs first, copies into
                           # web/public/audio/HOEREN/<dir>/ for serving
```

`build/mirror-audio.mjs` already mirrors a `HOEREN` top-level directory the
same way it mirrors `A1`…`C1` — no further wiring needed.

## Sets built so far

- **01 — Anrufbeantworter** (A2) — three short voicemail messages (a
  colleague introducing herself, a doctor's-office reminder, a delivery
  notice), each with 3 comprehension questions.
- **02 — Durchsagen** (B1) — three public-announcement passages (train
  station platform change, supermarket PA, radio traffic report), each with
  3 comprehension questions.
- **03 — Kurzvorträge** (B2) — three short monologue/report passages (an
  opinion piece on home-office work, a product review, a workplace policy
  update), each with 3 comprehension questions, denser vocabulary and
  Nominalstil-heavy phrasing matching the B2 grammar the curriculum already
  teaches.
